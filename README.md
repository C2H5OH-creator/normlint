# NormLint

NormLint — проект системы автоматизированного нормоконтроля академических документов: выпускных квалификационных работ, курсовых проектов и отчётов по практике.

Система разрабатывается для проверки структуры и оформления документов по ГОСТам, локальным нормативным документам и методическим указаниям образовательных организаций. Цель проекта — сократить трудозатраты на ручную проверку и помочь выявлять нарушения оформления.

Планируемые возможности:

- Проверка форматирования текста, заголовков, таблиц, рисунков, списков и библиографических записей.
- Настройка параметров и набора правил проверки.
- Создание профилей требований для разных вузов, кафедр и типов работ без изменения программного кода.
- Формирование понятных отчётов с выявленными нарушениями.
